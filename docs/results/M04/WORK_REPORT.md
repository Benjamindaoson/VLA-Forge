更新日期：2026-10-11。权威执行环境：RTX 3090 云服务器，项目位于 `/data/VLA-Forge/project/robot-vla`。

## 结论与验收边界

**核心纠正实验、数据集写入/重载验证、FP32 推理加速与私有交付已有实测证据；完整 M04 公开发布仍为 INCOMPLETE。** 未开始 M05 模型训练。

## 做出了什么

从 M02 的真实失败轨迹出发，恢复来源物理状态，采用冻结 SmolVLA 生成新的纠正动作，在 MuJoCo 中取得成功信号。对成功序列去重、独立物理重放两次，并将相机观测、状态、动作和来源写入 LeRobotDataset v3。

- **11 条新的 M04 纠正序列**，每条独立物理重放两次通过。
- 另有 **1 条单独标记的 M03 派生序列**，没有算作新的 M04 纠正。
- 数据集 **12 Episodes / 956 Transitions**，动作与状态写入后重载最大误差均为 0。
- 数据覆盖 **Goal task 6、M02 初始状态 6 和 7**；这是开发样本集，不是跨任务泛化验证。
- 登记生产尝试 **79 条**：12 条 Success 记录、67 条失败记录。Success 登记行包含重复动作序列，不能代替去重后的纠正数量，也不能作为标准 Benchmark 成功率。
- 30–50 条是未达到的扩展目标。当前不继续无上限搜索种子来扩大计数。

## 推理加速及真实动作验证

采用可选 CUDA Graph FP32 路径。动态视觉前缀保留 eager，捕获可复用的注意力及去噪计算；不改变模型、归一化、去噪步骤和 Action Chunk 配置。

| 完整动作块指标 | 原始 Eager | CUDA Graph |
| --- | ---: | ---: |
| P50 | 391.74 ms | 56.39 ms |
| P95 | 398.84 ms | 61.85 ms |
| P99 | 399.07 ms | 61.87 ms |

3 个真实观测 × 6 个噪声种子，共 **18 组配对**；动作输出最大差异为 0，随机数状态全部一致。预热后动作块推理 P50 加速 **6.95 倍**，计时不含前处理和仿真。

真实 MuJoCo 续跑对照中，双方均在 **21 个纠正动作后 Success=True**。动作、关节位置/速度、末端位姿和双相机帧的最大差异均为 0。

冷捕获约 **1.82 秒**。当前短续跑的冷启动策略循环 6.965 秒，历史 eager 参考为 5.558 秒；这不是同时执行的端到端实验，**不能声称整个任务加速 6.95 倍**。默认保持 eager，CUDA Graph 适用于能够复用 sampler 的持续执行场景。

## 数据集、成本与完整性

- LeRobot v3 r7 独立重载通过；图像编码后平均绝对误差 2.190（像素值单位）。
- 写入 36.478 秒，吞吐 26.21 Transitions/s。
- 来源家族分组用于隔离开发数据；两个故意制造的跨分组冲突被现有泄漏检查拒绝。M06 测试尚未开展。
- 登记策略循环共 **0.573466 GPU-hours**，每条新可信纠正约 **0.052133 GPU-hours**。包含失败尝试，但缺少完整加载、恢复、重放、编码和空闲成本，不是完整生产成本或云账单。
- 生产峰值 PyTorch allocated memory 0.898 GiB；CUDA Graph 微基准峰值 981,761,024 bytes。都不是 GPU 进程总显存。
- 237 个登记制品引用没有缺失；保留一条历史失败尝试的 JSON 哈希异常，动作数组与对应 NPZ 相同，但不能因此抹掉来源异常。
- 云端结项测试 **82 passed、1 条上游 Starlette 弃用警告**；Ruff 和编译检查通过。此处引用已保存的云端实验测试回执，本次 README 更新未重跑 GPU 实验。

## 可据实使用的项目描述

基于 SmolVLA 与 LIBERO/MuJoCo 构建机器人失败恢复和纠正数据流水线，生成 11 条通过两次独立物理重放的新纠正轨迹，形成 12 Episode / 956 Transition 的 LeRobot v3 开发数据集；在 RTX 3090 上实现 FP32 CUDA Graph 动作块推理优化，将预热后 P50 从 391.74 ms 降至 56.39 ms，并以 18 组输出一致性对照和真实仿真续跑验证正确性。数据范围为一个任务、两个来源初始状态。
