# M05 数据准入报告

**结论：纠正监督的工程准入有条件通过；只足以支持单任务、有限来源状态的受控可行性试验。未开展 M05 训练，不具备宣布跨任务提升或商业视觉数据授权完备的条件。**

## 已满足
1. 冻结的 r7：12 Episode、956 transitions、11 条新纠正和 1 条 M03 派生纠正；1 task、2 init states。
2. 实际执行的 7D 相对动作有限、范围合法，与原始 env_step_argument、成功重放及 parquet 完全对齐。8D 预动作状态及最后一步 terminal labels 精确匹配。
3. 包含双相机的完整数据在云端可内部复核；公开数值子集不替代视觉训练数据。
4. 两条有 Registry 来源歧义的失败记录被逻辑隔离，未污染 r7。
5. 所有开发及派生来源组冻结；此前 6 个受污染测试来源已退役。新的 400 个测试条件使用 init 40–49 与独立种子，文件/状态/BDDL 哈希已冻结，无旧状态字节交叉。

## 启动后续 M05 前仍须落实的条件
- 在另行授权的 M05 任务内冻结训练预算、同协议 Frozen Baseline 与指标，不先查看新的测试 outcome 再调参。
- 不把同一源状态派生的不同策略 seed 当作独立数据来源；训练归一化和样本选择只能使用开发数据。
- 完整视觉素材按现有研究/非商业使用边界处理；不能从工程准入推导商业或公开视觉再分发权限。
- 本次 Goal task 4 的三次有界尝试均失败，不能声称纠正能力已跨任务验证；当前数据规模不支持泛化结论。
- 12 条全部成功的纠正段是选择后的监督数据，不代表策略成功率。干预策略产生动作与无干预重放图像的观测语义已明确，不伪称原始策略自然生成。

m05_admission.json 是机器可读 gate；training_freeze.json 是确切训练文件；source_groups.json 与 independent_test_freeze.json 是禁止泄漏的来源约束。训练执行：False。

## 必须保留的输入契约
固定 checkpoint 的特征配置声明 state 为 6 维，但实际 Normalizer 使用 8 维；既有已验证 Runner 保留完整 8D 位姿与夹爪状态，由 SmolVLA 补齐到 max_state_dim。未来训练入口必须显式兼容这个已冻结契约，不能截断状态或假设通用训练器默认配置可直接使用。模型、Processor、Normalizer 文件均已重新计算 SHA256 并记入 training_freeze.json。本次未执行训练 forward/backward，不把数据工程通过称为训练器已验收。
